# Remote agent tool definitions

> Generated by `scripts/generate-remote-agent-tool-definitions.mjs`. Edit the Posse
> catalog or the posse-remote role policy, then regenerate this document.

This is the human-readable view of the definitions remote agents can receive.
Posse is the definition authority for names, descriptions, visible parameters,
and batch/parallel-call behavior. `posse-remote` is the issuance-policy authority for roles
and suites. Remote catalog summaries are display metadata and are not substituted
for these definitions.

The exact machine pin is [test/fixtures/agent-tool-contract.json](test/fixtures/agent-tool-contract.json).

## Runtime narrowing

The role lists below are maximum issuance ceilings. A request can narrow them by
provider, requested suite, read/write policy, negotiated local capabilities, and
available memory. Atlas memory read/feedback tools disappear when the runtime reports
zero memories. Prefetch-only Atlas actions are absent from the callable lists.

The `fix` worker resolves to the `dev` tool role and therefore uses the dev ceiling.
Delegator, preflight, summary, and Atlas-warm roles have no callable tool ceiling.
A signed citation child combines its inherited terminal handoff with the separately
issued child cursor, so the subagent view below contains both coordination definitions.

`atlas.code.survey` is a callable action for researcher, planner, dev, and assessor.
It is also system-prefetch capable, so the runtime may deliver its result before an
agent call. Prefetch support does not remove its callable definition.

Read exact missing file context through the deterministic fallback. When ATLAS is active, successful ATLAS source retrieval already counts as file-content evidence. This reader covers remaining ATLAS evidence gaps, exact mutated or non-indexed state, an unsupported operation, or when ATLAS is unavailable. The first read of a file locks the chain until you classify that file as relevant or irrelevant.
